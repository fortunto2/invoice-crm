## Содержание

### Введение

Каждый фрилансер рано или поздно сталкивается с необходимостью выставлять счета. Варианты обычно такие:

1. **Excel/Google Sheets** — работает, но выглядит непрофессионально и неудобно для автоматизации
2. **SaaS-сервисы** (FreshBooks, Invoice Ninja hosted, Zoho Invoice) — удобно, но платная подписка и ваши данные на чужих серверах
3. **Self-hosted решения** (Invoice Ninja, Crater) — полноценные веб-приложения с базами данных, часто избыточно для одного человека

Я выбрал четвёртый путь: написал CLI-утилиту, которая генерирует профессиональные PDF-инвойсы из YAML-файлов. Никаких баз данных, никаких веб-интерфейсов, всё хранится в обычных текстовых файлах и отлично ложится в git.

### Почему файлы, а не база данных

**Git-friendly.** Вся история изменений клиентов, провайдеров, шаблонов — в системе контроля версий. Нужно откатиться? `git revert`. Ведёте несколько юрлиц? Ветки.

**Читаемость.** Открыл файл в любом редакторе — сразу видно все данные. Не нужны админки и дашборды.

**AI-совместимость.** Claude Code, Cursor, Copilot — любой AI-ассистент может читать YAML-конфиги и генерировать инвойсы одной командой. Не нужны API-ключи и OAuth.

**Бэкапы.** Просто скопировал папку. Или запушил в приватный репо.

### Архитектура

```
invoice-crm/
├── crm.py              # Основной CLI (~600 строк)
├── qr.py               # Генерация QR-кодов
├── schemas.py          # Pydantic-схемы
├── providers/          # Ваши компании (YAML)
├── clients/            # Ваши клиенты (YAML)
├── templates/          # Jinja2-шаблоны (HTML+CSS)
└── archive/            # Сгенерированные PDF
```

### Генерация инвойса

```bash
# Установка
git clone https://github.com/fortunto2/invoice-crm.git
cd invoice-crm
make install

# Генерация
uv run python crm.py invoice acme-corp --qty 40 --rate 100
```

На выходе — профессиональный PDF с:
- Реквизитами сторон
- Таблицей услуг
- QR-кодом для оплаты (формат зависит от валюты)
- Опционально: цифровой подписью

### QR-коды для платежей

Одна из killer-фич — автоматическая генерация QR-кодов в нужном формате:

| Валюта | Формат | Где сканировать |
|--------|--------|-----------------|
| EUR | EPC/SEPA | Любое европейское банковское приложение |
| TRY | EMVCo (TR.TCMB.FAST) | Турецкие банки |
| USD | SWIFT-текст | Ручной ввод |
| USDT/BTC | Криптоадрес | Кошельки |

Европейский клиент сканирует QR телефоном — и все реквизиты уже заполнены. Магия.

### Работа с AI-ассистентами

Инструмент специально спроектирован для работы с AI-агентами:

**Я:** "Сгенерируй инвойс для ACME за февраль, 40 часов по 100 евро"

**Claude Code:** *читает YAML-файлы, запускает команду, получает PDF*

**Я:** "Добавь нового клиента BigCorp с такими же условиями как ACME"

**Claude Code:** *создаёт новый YAML по образцу*

Никаких веб-интерфейсов, API, авторизаций — просто файлы и CLI.
