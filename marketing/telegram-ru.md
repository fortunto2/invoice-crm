# Пост для Telegram-каналов

## Версия 1 (для dev-каналов)

🧾 **Open-source генератор инвойсов для фрилансеров**

Сделал CLI-тулзу для генерации PDF-инвойсов из YAML-файлов. Без базы данных, без SaaS, всё в текстовых файлах → отлично ложится в git.

Фичи:
• Профессиональные PDF с QR-кодами для оплаты
• EPC/SEPA для EUR, EMVCo для TRY, SWIFT, крипта
• Цифровые подписи, шифрование (опционально)
• Работает с Claude Code и другими AI-агентами

Стек: Python, Pydantic, Jinja2, WeasyPrint, uv

```bash
uv run python crm.py invoice my-client
```

GitHub: github.com/fortunto2/invoice-crm

MIT, бесплатно, самохостинг.

## Версия 2 (для каналов про фриланс)

💰 **Бесплатная альтернатива платным сервисам для инвойсов**

Устал платить $10-30/мес за сервисы типа FreshBooks? Я тоже.

Написал простой генератор инвойсов:
• Все данные в YAML-файлах (клиенты, реквизиты)
• Одна команда → готовый PDF
• QR-коды для оплаты (европейские банки сканируют)
• Бесплатно, open source, работает локально

Для айтишников-фрилансеров, которым не нужна вся эта CRM-обвязка, а нужны просто красивые инвойсы.

→ github.com/fortunto2/invoice-crm
