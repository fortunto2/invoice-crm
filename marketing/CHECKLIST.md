- GitHub stars (goal: 100 in first week)
- Clones/unique visitors (GitHub Insights)
- Upvotes on each platform

## Notes

- Don't spam multiple subreddits on the same day
- Wait 24-48h between Reddit posts to different subs
- Be genuine in comments, don't be overly promotional
- If something gets traction, engage heavily for the first few hours
